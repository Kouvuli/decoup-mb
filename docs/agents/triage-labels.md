# Triage labels

| Canonical state role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting maintainer evaluation |
| needs-info | needs-info | Awaiting additional information |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human execution or judgment |
| wontfix | wontfix | Rejected / not being actioned |

Use exactly one state role and one category (`bug` or `enhancement`) per triaged request. These are local file values; no remote labels have been created. Wayfinder decision statuses and implementation lifecycle statuses are defined separately in [issue-tracker.md](issue-tracker.md).

Edit this table to change the vocabulary. Already-ready generated tickets do not need triage.
